# Contributing to Aura Partner Research

First off, thank you for considering contributing to Aura Partner Research! It is people like you who make this tool a powerful discovery engine for B2B partner exploration.

## Code of Conduct

By participating in this project, you agree to abide by our Code of Conduct:
- Be respectful and professional.
- Avoid harassment or offensive behavior.
- Help foster an inclusive community.

## How Can I Contribute?

### Reporting Bugs
If you find a bug, please open an Issue and include:
- A clear, descriptive title.
- Steps to reproduce the bug.
- Expected vs. actual behavior.
- Console logs or Python server error printouts.

### Submitting Pull Requests
1. Fork the repository.
2. Create a new branch: `git checkout -b feature/my-new-feature`.
3. Make your changes and write descriptive commit messages.
4. Verify code correctness (compile React with `npm run build` and test Python scripts syntax).
5. Push to your fork and submit a Pull Request.
